PYTHON / AEROSPACE / 2026

Aircraft Performance Calculator

I built this to connect the aircraft performance equations I was learning into one working Python model. It calculates atmosphere, lift, drag, aerodynamic efficiency, climb performance, range, and endurance from a flight condition.

23 tests passing · 4 performance plots · 5 Python modules

01 / HOW IT WORKS

From a flight condition
to performance.

altitude + airspeed ↓ atmosphere ↓ lift + drag ↓ power + climb ↓ performance
q = ½ρV² dynamic pressure
CL = W / qS required lift coefficient
CD = CD0 + kCL² drag polar
ROC = (T - D)V / W rate of climb
READ MORE

The calculator is split into five modules instead of keeping every calculation in one file.

aircraft.py aircraft configuration and validation
atmosphere.py ISA atmospheric properties
aerodynamics.py lift, drag, required CL, and L/D
propulsion.py thrust calculations
performance.py power, climb, range, and endurance

It did not start this organized. Splitting the model into modules made it much easier to change one part without breaking everything else.
