Aircraft Performance Calculator

I built this because I wanted to take aircraft performance equations I had been reading about and actually connect them in code. The program takes a flight condition and aircraft parameters, then works through atmosphere, lift, drag, efficiency, climb performance, range, and endurance.

23 tests passing · 4 generated plots · 5 core modules

HOW I APPROACHED IT

Start with the flight condition.

I started with the basic level-flight relationships and built outward from there. Airspeed and altitude determine the atmospheric condition and dynamic pressure. From that, the model solves for the lift coefficient needed to support the aircraft, estimates drag, and then uses the resulting forces to calculate power and climb performance.

I initially thought the individual equations would be the difficult part. The more interesting part ended up being making sure they worked together consistently, especially when changing airspeed.

altitude + airspeed atmosphere lift + drag power + climb performance
q = ½ρV² dynamic pressure
CL = W / qS required lift coefficient
CD = CD0 + kCL² drag polar
ROC = (T - D)V / W rate of climb
more about the code

The calculator is split into five core modules instead of keeping every calculation in one file.

aircraft.pyaircraft configuration and validation
atmosphere.pyISA atmospheric properties
aerodynamics.pylift, drag, required CL, and L/D
propulsion.pythrust calculations
performance.pypower, climb, range, and endurance

Splitting the calculations into modules happened after I had the basic model working. It made the code much easier to test and extend.

WHERE THIS MODEL STOPS

It is not a flight simulator.

I kept the first version focused on classical subsonic fixed-wing performance so I could understand and test the underlying relationships before making the model more complicated.

  • no compressibility effects
  • no detailed engine maps
  • no Reynolds-number corrections
  • no wind model
  • no takeoff or landing model
  • no stability or control model
