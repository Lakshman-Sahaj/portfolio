# Lakshman Sahaj Portfolio

## Publish with GitHub Pages

1. Create or use the public repository `Lakshman-Sahaj/github-portfolio`
2. Upload `index.html`, `styles.css`, `script.js`
3. Add your current resume PDF using the exact filename `resume.pdf`
4. Commit the files
5. Go to Settings → Pages
6. Set Source to Deploy from a branch
7. Choose `main` and `/ (root)`
8. Save

Your site will be at:

https://lakshman-sahaj.github.io/github-portfolio/
