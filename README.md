# Lakshman Sahaj Portfolio

## Publish with GitHub Pages
1. Create a **public** repository named `aritrasaha1.github.io`
2. Upload `index.html`, `styles.css`, `script.js`
3. Add your current resume PDF using the exact filename `resume.pdf`
4. Commit the files
5. Go to **Settings → Pages**
6. Set **Source** to `Deploy from a branch`
7. Choose `main` and `/ (root)`
8. Save

Your site will be at:
`https://aritrasaha1.github.io`

## Update projects later
Each placeholder is an `<article class="project-card">` in `index.html`.
Replace its title, description, and placeholder visual with your real content when ready.
